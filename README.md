# YOLOv8 Recycling Object Detection

A computer-vision coursework project that fine-tunes YOLOv8 for real-time detection of recyclable object categories from a webcam.

## Contents

- `app.py` - webcam inference application
- `category_mapping.py` - category mapping helpers
- `image_downloader.py` - image acquisition helper
- `train_test_divide.py` - dataset preparation helper
- `requirements.txt` - Python dependencies

The trained weights, dataset images, and training runs are intentionally excluded. Obtain or create a legally redistributable dataset separately, then configure paths in the scripts.

## Status

This is an academic prototype. The dataset and pretrained YOLOv8 weights have separate licensing terms and are not redistributed here.
